# Register your `.is-at-the.top` subdomain

This repository is where the `.is-at-the.top` registry lives.

Want your own place on the internet? You can claim a subdomain like:

`yourname.is-at-the.top`

The service is built around GitHub, so the registry stays public and changes can be reviewed openly.

---

## Before you start

A few things worth knowing:

* `.is-at-the.top` is for **personal and non-commercial use**.
* You get one subdomain per registration.
* Some names are reserved and can't be claimed.
* Your subdomain needs to point somewhere you control or are allowed to use.
* Don't use your subdomain for spam, phishing, malware, impersonation, or anything illegal.
* A subdomain isn't yours forever in the absolute sense. We may need to remove or suspend it if it breaks our rules or puts the service at risk.

Please read the [Terms of Service](https://is-at-the.top/terms) before submitting.

---

## How to get one

1. **Fork this repository.**
2. Add your subdomain configuration to [`domains/`](./domains).
3. Make sure your file follows the [registration documentation](https://is-at-the.top/docs).
4. Open a pull request.
5. Our checks will run automatically.
6. We'll review the request and let you know if anything needs changing.
7. Once your PR is merged, your DNS record will be published automatically.

That's it.

If something isn't right, we'll tell you what needs fixing. You don't need to open a new PR every time, just update the existing one.

### Please don't blindly generate your PR with AI

You can use whatever tools you like, but **you are responsible for what you submit**.

If you don't understand what a file does, don't submit it yet. A five-minute manual fix is much faster than an invalid PR going back and forth.

## The first 500

The first **500 accepted registrations** are special.

They're the **Founding 500** — the people who were here before `.is-at-the.top` really took off.

Each one gets a numbered Founder badge:

`Founder #001` → `Founder #500`

There will only ever be 500.

After that, the service will remain focused on keeping personal subdomains affordable.

## Something broken?

If your PR fails a check, read the error first. Most problems are small things like an invalid name or DNS record.

If you're still stuck, open a [issue](https://github.com/is-at-the-top/register/issues/new?template=question.yml).

Please don't open an issue just to ask us to merge your PR faster. We promise the red notification isn't helping. :)

---

## Report abuse

### **Don't use GitHub Issues for sensitive abuse reports.**

Found a subdomain being used for something that shouldn't be there?

Please report it through our [abuse report page](https://is-at-the.top/abuse) or [GitHub Issues](https://is-at-the.top/abuse).

Please include the subdomain and enough information for us to understand what's happening.

---

## Security

Found a security vulnerability in the registry, website, API, or infrastructure?

Please **don't** open a public issue.

Follow our [security policy](./SECURITY.md) for private reporting.
